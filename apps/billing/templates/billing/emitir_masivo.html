    {% translate "Cómo se llena la planilla" %}
    • {% blocktranslate %}Cada fila con Tipo DTE abre un documento nuevo.{% endblocktranslate %}
    • {% blocktranslate %}Si el documento tiene más de un ítem o más de una referencia, se agrega una fila nueva donde solo van las columnas correspondientes al ítem o a la referencia, y las demás vacías.{% endblocktranslate %}
    • {% blocktranslate %}Use como guía las planillas de ejemplo de arriba: la primera fila es el encabezado y se ignora, y las columnas se leen por posición. El CSV usa ; como separador.{% endblocktranslate %}
    • {% blocktranslate %}En un XLSX las celdas de fecha sirven con cualquier formato, mientras sean fechas de verdad y no texto. En un CSV, o si escribe una a mano como texto, use AAAA-MM-DD.{% endblocktranslate %}
    • {% blocktranslate %}La columna Folio es obligatoria, un número mayor a 0, y no puede repetirse dentro de un mismo tipo de documento. Solo identifica al documento dentro de la planilla: el folio real lo asigna el CAF al emitir.{% endblocktranslate %}
    • {% blocktranslate %}Si la planilla tiene un error, se informa el primero, con su fila, y no se emite nada hasta corregirlo.{% endblocktranslate %}
    • {% blocktranslate %}Con el modo Solo ver los documentos se descargan, en YAML, los documentos que leyó la biblioteca: no se emite ni se envía nada, y la opción de PDF no aplica.{% endblocktranslate %}
    • {% translate "Se recomienda no más de 100 documentos por planilla." %}
